The Power of the Pipe!

The Power of the Pipe!

What is the pipe?

  • The pipe operator written as |> or %>%, takes an ouput of one function and ‘pipes’ it to the next function
  • It is like a conveyor belt, each function performing an action on the data before passing it on to the next step
  • The pipe is where the tidyverse comes into its own - helping us to build clear, step-by-step workflows


Shortcut! Ctrl + Shift + M on Windows and Cmd + Shift + M on a Mac

The Pipe in Action

Without the pipe, we typically have to nest functions

# From a dataset, select participants aged over 25 
# and show the first few rows
head(filter(my_data, age > 25))


The pipe makes the code much more intuitive and readable

# From a dataset, select participants aged over 25 
# and show the first few rows
data %>% 
  filter(my_data > 25) %>% 
  head()

The Pipe in Action

The value of the pipe becomes clear when we start adding steps to the transformations we execute on our dataset

# A simple pipeline
my_data %>% 
  filter(Condition == "Treatment") %>% # Step 1: Keep only 'Treatment' group
  select(ID, Q1, Q2) %>% # Step 2: Select ID and two questionnaire scores
  mutate(total_score = Q1 + Q2) # Step 3: Create a new variable 'total_score'

group_by()

Often we will want to perform an operation on only a group of our participants

  • e.g. by experimental condition or participant group


The group_by() function tells R how to split your data into these logical groups.

# Group the dataset by the 'Condition' variable
df %>%
  group_by(Condition)

This function doesn’t change the visible output much on its own, but it’s a critical first step. It adds grouping information to the tibble, so that any subsequent functions will operate on each group separately.

group_by() and summarise()

We can use group_by() with summarise() to calculate summary statistics by group

# Group by Condition, then calculate the mean age for each group
df %>%
  group_by(Condition) %>%
  summarise(mean_q1 = mean(Q1), n = n())
# A tibble: 2 × 3
  Condition mean_q1     n
  <chr>       <dbl> <int>
1 Control      4.33     6
2 Treatment   NA        4

Here, we’re creating a new tibble with one row for each group (Condition). We’ve created two new variables in our output: mean_age, which holds the average age for each group, and n, which counts the number of observations in each group using the n() function.

group_by() and summarise()

We can group by multiple conditions

# Group by Condition, then calculate the mean age for each group
df %>%

mutate() is used for adding columns to your dataset or modfying existing ones

Creating and Modifying Variables with mutate()

You can also use mutate() to create a new categorical variable based on a logical condition in another column.

  • ifelse() is useful here!
# Create a new group column based on whether participants responded 
# over a value on a questionnaire item
my_data %>%
  mutate(group = ifelse(Q1 > 3, "A", "B")) 
# A tibble: 5 × 6
  ID      age Condition    Q1    Q2 group
  <chr> <dbl> <chr>     <dbl> <dbl> <chr>
1 P001     30 Control       4     5 A    
2 P002     22 Treatment     5     4 A    
3 P003     45 Control       5     5 A    
4 P004     19 Treatment     3     4 B    
5 P005     28 Control       2     3 B

In this example, we’re using ifelse() inside of mutate(). The ifelse() function takes three arguments: a condition (age > 25), a value if the condition is true (“Older”), and a value if the condition is false (“Younger”). This is a powerful way to recode your data for analysis.

Changing Data Types with mutate()

As we learned last week, data type is very important. We can use mutate() with as. functions to change data type

  • as.numeric(): Converts data into a numeric type (for continuous numbers).

  • as.character(): Converts data into a character type (for text).

  • as.factor(): Converts data into a factor (for categorical data with defined levels).

Correct the data type using mutate() and as.numeric()

corrected_data <- bad_type_data %>%
  mutate(age = as.numeric(age))
# Check the new data types
glimpse(corrected_data)
Rows: 3
Columns: 3
$ ID        <chr> "P001", "P002", "P003"
$ age       <dbl> 30, 22, 45
$ Condition <chr> "Control", "Treatment", "Control"

In this code, we take our bad_type_data, and pipe it into mutate(). We’re creating a new age column by applying as.numeric() to the old age column. When we check the result, we see that age is now a <dbl> or “double,” which is a numeric type, and we can perform calculations on it. This is a very common and useful step in data wrangling.

Changing Data Types with mutate()

  • Keep an eye out for conversion issues introducing NAs (e.g. any non-numeric value becoming an NA)
    • You can try parse_number() to extract numbers from a string, which can prevent some of these issues.

Wide vs Long Data

Wide and Long Format

Last week we introduced the concept of long and wide data formats.

tidyverse provides two key functions for converting between them:

  • pivot_longer(): converts wide data to long
  • Takes multiple columns and collapses them into two columns: one for the variable names and one for the values.
  • Example: Turn Q1, Q2, Q3 columns into one ‘Question’ column and one ‘Score’ column.

pivot_longer()

#Data in wide format
head(my_data)
# A tibble: 5 × 5
  ID      age Condition    Q1    Q2
  <chr> <dbl> <chr>     <dbl> <dbl>
1 P001     30 Control       4     5
2 P002     22 Treatment     5     4
3 P003     45 Control       5     5
4 P004     19 Treatment     3     4
5 P005     28 Control       2     3

pivot_longer()

my_data_long <- my_data %>%
  pivot_longer(
    cols = c(Q1, Q2), # Columns to be collapsed
    names_to = "Question", # Name of new column that holds old column names
    values_to = "Score" # Name of new column that holds the values
  )
my_data_long
# A tibble: 10 × 5

   <chr> <dbl> <chr>     <chr>    <dbl>

 2 P001     30 Control   Q2           5

 6 P003     45 Control   Q2           5

Wide and Long Format

  • pivot_wider(): Converts long data to wide data.
    • Takes two columns (one of names, one of values) and spreads them across multiple new columns.
    • Example: Turn ‘Timepoint’ and ‘Score’ columns into ‘Time1_Score’ and ‘Time2_Score’ columns.

pivot_wider()
