Polishing a Single Plot


Creating a plot is only the first step. To make it truly effective, we need to control its appearance. This means moving beyond the default themes and adding annotations that tell a story.

Polishing a Single Plot


Let’s start with a basic plot using the palmerpenguins dataset.

# Our base plot
base_plot <- ggplot(penguins, 
                    aes(x = flipper_length_mm, y = bill_length_mm, color = species)) +
  geom_point(alpha = 0.8) +
  labs(title = "Penguin Bill Length vs. Flipper Length",
       x = "Flipper Length (mm)", y = "Bill Length (mm)")

base_plot + theme_minimal()

A Deep Dive into theme()


The theme() function is your control panel for the non-data elements of your plot. You can change almost anything: fonts, backgrounds, gridlines, text positions, and more.


Each element you modify is an argument to theme(), and you use special element_ functions to specify the new look.

  • element_text(): For labels, titles, and axis text.
  • element_rect(): For rectangular areas, like the plot background.
  • element_line(): For lines, like gridlines and axis lines.
  • element_blank(): To remove an element completely.

Customising a Plot’s Theme


Let’s transform our base plot. We’ll change the fonts, move the legend to the bottom, and style the panel background and gridlines. Note how we can build these changes up layer by layer.


base_plot +
  theme_minimal() +
  theme(
    legend.position = "bottom",
    plot.title = element_text(size = 20, face = "bold", hjust = 0.5),
    axis.title = element_text(size = 14),
    panel.grid.minor = element_blank(),
    panel.background = element_rect(fill = "#F0F8FF", color = "grey80")
  )

Customising a Plot’s Theme


Creating a Reusable Custom Theme


Rewriting theme() code for every plot is tedious. A better workflow is to save your customisations as a new function. This ensures consistency and saves a lot of typing.

Let’s create theme_psy6422() and apply it to our plot.


# Define the custom theme function
theme_psy6422 <- function() {
  theme_minimal() +
  theme(
    legend.position = "bottom",
    plot.title = element_text(size = 20, face = "bold", hjust = 0.5),
    axis.title = element_text(size = 14),
    panel.grid.minor = element_blank(),
    panel.background = element_rect(fill = "#F0F8FF", color = "grey80")
  )
}

Telling a Story with Annotations


A great visualisation often guides the viewer’s attention to the most important findings. We can do this with annotations.

The ggrepel package is essential for adding labels to data points without them overlapping and becoming unreadable. Let’s label the penguins with the longest and shortest bills.


# First, find the penguins to label
penguins_to_label <- penguins %>%
  filter(bill_length_mm == max(bill_length_mm, na.rm = TRUE) |
         bill_length_mm == min(bill_length_mm, na.rm = TRUE))

Telling a Story with Annotations


# Now, add the labels with geom_text_repel()
base_plot +
  geom_text_repel(data = penguins_to_label, 
                  aes(label = paste(species, "Penguin")),
                  box.padding = 1.5,
                  point.padding = 0.5) +
  theme_psy6422()

Adding Rich Text with ggtext


What if you want to add bold, italics, or even colours to your titles and labels? The ggtext package lets you use Markdown and HTML for rich text formatting.

Adding Rich Text with ggtext


Use element_markdown() inside the theme() function.


base_plot + 
  labs(title = "<span style='color:#E87D73;'>Adelies</span> have the shortest bills. <span style='color:#6F9CF8;'>Gentoos</span> have the longest flippers.") +
  theme_psy6422() +
  theme(
    plot.title = element_markdown(size = 20, lineheight = 1.2)
  )

Composing Plots with patchwork


Often, a single plot isn’t enough to tell the whole story. You might need a scatterplot to show a relationship, a boxplot to show distributions, and a bar chart for counts. The patchwork package makes combining these plots incredibly simple and intuitive.


The syntax is based on arithmetic operators:

  • +: Places plots next to each other.
  • /: Stacks plots on top of each other.
  • (): Controls the order of operations for complex layouts.

Creating Plots to Combine


First, let’s create two separate plots from our penguins data. We’ll save each object with a unique name.


# Plot 1: The scatterplot we've been using
p_scatter <- ggplot(penguins, 
                    aes(x = flipper_length_mm, y = bill_length_mm, color = species)) +
  geom_point(alpha = 0.8) +
  theme_psy6422() 

# Plot 2: A boxplot of flipper length by species
p_boxplot <- ggplot(penguins, aes(x = species, y = flipper_length_mm, fill = species)) +
  geom_boxplot() +
  theme_psy6422()

Advanced Layouts and Annotations


patchwork gives you full control. You can create complex nested layouts and add a single, unified title, caption, and tags to the entire composition with plot_annotation().


# Create a third plot for a more complex layout
p_density <- ggplot(penguins, aes(x = bill_length_mm, fill = species)) +
  geom_density(alpha = 0.7) +
  theme_psy6422()

# (p_scatter | p_boxplot) / p_density
(p_scatter + p_boxplot) / p_density +
  plot_annotation(
    title = "Exploring Palmer Penguin Characteristics",
    subtitle = "A multi-panel analysis",
    caption = "Data Source: palmerpenguins R package",
    tag_levels = "A"
  )

Unifying Legends of the Same Type with plot_layout()


patchwork has the ability to collect legends from multiple plots of the same type into a single, shared legend.

You use plot_layout(guides = 'collect'). This is essential for creating clean, professional figures.

  geom_point(alpha = 0.7)

# Plot 2: Bill Depth vs. Body Mass
p2 <- ggplot(penguins, aes(x = bill_depth_mm, y = body_mass_g, color = species)) +
  geom_point(alpha = 0.7)

# Plot 3: Flipper Length vs. Body Mass
p3 <- ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g, color = species)) +
  geom_point(alpha = 0.7)

# Combine them
(p1 + p2) / p3 +

Unifying Legends for Different Plot Types with ggarrange


If you want to unify legends from plots of different types, you can use ggarrange from the ggpubr package.


 # Create the original plots
p_scatter <- ggplot(penguins, aes(x = flipper_length_mm, y = bill_length_mm, color = species)) +
  geom_point(alpha = 0.8) + 
  theme_psy6422()

p_boxplot <- ggplot(penguins, aes(x = species, y = flipper_length_mm, fill = species)) +
  geom_boxplot() + 
  theme_psy6422()

# ggarrange handles the incompatible legends automatically
ggarrange(p_scatter, p_boxplot,
          common.legend = TRUE,
          legend = "bottom")

Making Compositions Interactive


We’ve polished our plots and composed them into a single figure. The final step is to bring them to life. While ggplotly() is fantastic for single plots, it does not work directly on a patchwork object.

To create an interactive multi-panel figure, we need to use plotly’s own composition function: subplot().

The subplot() Workflow


The workflow is similar to patchwork, but with plotly functions:

  1. Create your individual ggplot objects.

  2. Convert each one into a plotly object using ggplotly().

  3. Combine the resulting plotly objects using subplot().

The subplot() Workflow


Let’s convert our scatterplot and boxplot.


# Convert each ggplot to a plotly object
plotly_scatter <- ggplotly(p_scatter)
plotly_boxplot <- ggplotly(p_boxplot)

# Combine them with subplot()
subplot(plotly_scatter, plotly_boxplot, nrows = 1)

The subplot() Workflow


Controlling Layout and Sharing Legends in subplot()


subplot() has arguments to control the layout, just like patchwork. You can specify the number of rows (nrows) and share legends.


Let’s create a 2x2 layout and share the legend between the plots. This creates a linked, interactive dashboard where clicking on a legend item will toggle the data across all plots simultaneously.

# Recreate plots with consistent legend groups
p1 <- ggplot(penguins, aes(x=flipper_length_mm, y=bill_length_mm, color=species)) + geom_point()
p2 <- ggplot(penguins, aes(x=species, y=flipper_length_mm, color=species)) + geom_boxplot()
p3 <- ggplot(penguins, aes(x=bill_length_mm, color=species)) + geom_density()
p4 <- ggplot(penguins, aes(x=bill_depth_mm, color=species)) + geom_density()

subplot(p1, p2, p3, p4, nrows = 2, shareX = FALSE, shareY = FALSE) %>%
  layout(title = "Interactive Penguin Dashboard")

Controlling Layout and Sharing Legends in subplot()


Summary


R has many tools that allow us to create advanced, publication-quality visualisations:

  • Polish: Use theme(), ggrepel, and ggtext to make a single plot clear, beautiful, and informative.
  • Compose: Use patchwork to combine multiple plots into a single, cohesive visual narrative.
  • Interact: Use plotly and subplot() to turn your static compositions into dynamic, explorable dashboards.
