Finding Data

What Kind of Data Should I Choose?


For your project, don’t stress over which data to choose. The data is merely an excuse for the visualisation. If you have a choice, choose simple over complex. Importantly, find a dataset with variables you understand.

Where Can I Find Data for My Project?


There are many places you can look to find data for your mini project

  • Current or past supervisors

  • Single papers with open data

  • Data repositories (e.g., ONS)

Papers with Open Data


Many papers are now published accompanied by open data. Sometimes these are indicated by an Open Science Badge. To earn the badge, data must be digitally shared, there must be a data dictionary, and there needs to be a license.


For example, look at the current table of contents for Psychological Science

Data Repositories


You can look in data repositories for data as well. For example, check out the Office for National Statistics.


You can search for a keyword(s) like anxiety and then click for the report and click for the underlying data.

Reading Data into R

Reading Data into R: An Example


Let’s look at an example dataset.

We will use the Palmer Penguins dataset from the Long Term Ecological Research Network in Antarctica.

Please download the pengins.csv file from Blackboard and save it in a project folder.

You should also open a new R Script and save it in the same project folder.

Install and Load Package data.table


There are different ways to read tables into R. We will use the package data.table. If you haven’t installed it before, in the console type install.packages("data.table")


Once you’ve installed it, in your R Script, load the package:


library(data.table) #loading package data.table

Reading in csv File


Now we can load our csv file into R using the fread() function from the data.table package. If you saved your data and script in a project folder, you won’t need to provide the whole path to the data. We will call this dataset penguins.

For best practice, (install and) load the here package.

# Example: Calling data using "here" and "data.table" packages + an RStudio project
# Datasets is the name of the subfolder within my project folder
# penguins.csv is the name of the csv file, stored in the Datasets folder
library(here)
penguins <- fread(here("Datasets", "penguins.csv"))


# Example: Calling data using the "data.table" package + RStudio project
penguins <- fread("Datasets/penguins.csv")


# Example: Calling data using the "data.table" package and full file path
# This is the least recommended way
penguins <- fread("/Users/sabrinaburr/Desktop/PSY6422/Datasets/penguins.csv")

Summary of Data

  • The total number of observations for each column
  • Mean, median, quartiles
  • Min and max
  • Class (i.e., type of variable)
  • Number of missing values

Column Names


If we want to know the column names (i.e., variable names) in our table, we can use the function names()


names(penguins) # names of columns/variables
[1] "V1"                "species"           "island"           
[4] "bill_length_mm"    "bill_depth_mm"     "flipper_length_mm"
[7] "body_mass_g"       "sex"               "year"

Dimensions of the Data


If we want to know the number or rows and columns we can use the dim() function


dim(penguins) # number or rows and columns in data
[1] 344   9

Frequency Count of a Column


If we want to know the frequency count of a column in our data we can use the table() function and call a specific column using the format nameofdata$nameofvariable


table(penguins$island) # frequency count for the 'island' column

   Biscoe     Dream Torgersen 
      168       124        52

Mean and Median of a Column


If we want the mean (or average) for a column/variable we can use the mean() function. If we want the median, we can use the median() function. Again, we will call a specific column using the format nameofdata$nameofvariable


mean(penguins$flipper_length_mm, na.rm = TRUE)
[1] 200.9152


median(penguins$flipper_length_mm, na.rm = TRUE)
[1] 197


Notice the na.rm = TRUE option. We are asking R to evaluate any missing values as NA and calculate the mean and median based on the remaining values.

Note: If your variable name has spaces in it, you need to put tick marks (`) around the variable name.
